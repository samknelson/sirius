---
name: Bulk enqueue modal choices
description: Owner's expectation for consistent new/existing bulk-message and template choices across enqueue surfaces.
---

Every bulk-message enqueue surface, including Employer Compliance and worker
lists, must offer an existing message as well as creating a new one, with
optional template selection available in the enqueue modal.

**Why:** The owner explicitly repeated the need to reuse existing messages and
wants staff to select prepared letter wording without navigating elsewhere.

**How to apply:** Reuse the existing template library and message editor, not a
second template system. Unselected templates preserve existing wording. Applying
a template to an existing draft affects all recipients, so explain that effect
before submission and preserve unrelated channel settings.

Adding recipients to an employer-compliance message must retain the report
figures and run date already captured by that message.

**Why:** Silently replacing a report snapshot would change the reference point
of letters already prepared for earlier recipients.

**How to apply:** Refuse incompatible report contexts with an actionable message
instead of silently rebinding or recalculating existing recipients' letters.
