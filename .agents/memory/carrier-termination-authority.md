name: Carrier termination authority
description: Product and evidence boundaries for explicit membership termination exports.
---

Termination settings include ended subscribers/dependents independently; they
must never become general filters excluding active roles. Legacy snapshots
remain omission mode unless explicitly opted in. The user subsequently chose
wizard-only settings: NEW runs start subscriber on, dependent off, lookback 1.
Existing runs must never silently inherit these new defaults. The default
window is the previous completed calendar month's coverage ends, not event dates:
a November event means October 31 was last covered.

**Why:** The user explicitly distinguished ended-person inclusion from active
population filtering and prohibited silently activating live carrier delivery.
Analyst examples (Carelon October 31; Delta/Dyntl September 30) establish
YYYYMMDD formatting only, never a status code or blank-status validity.

**How to apply:** Dyntl means Dentwell/LADC. Use carrier reference evidence for
required action/status fields; visibly block unresolved contracts rather than
inventing codes. Retained inferred history may be usable as stored-coverage
evidence, but missing/unprocessed coverage alone is not a termination decision.
Keep eligibility, inference/backfill policy and delivery activation outside this work.
