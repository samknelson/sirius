# Postal SVG fixture

`benefits11-logo.svg` is the public, path-based logo downloaded from:

https://www.benefits11.org/wp-content/uploads/2025/08/UNITE-HERE-11-health-benefit-fund-logo-rgb-color.svg

It is stored unchanged (13,340 bytes; 240 × 56.75; path outlines, groups,
transforms and fill colors) so postal regression tests do not depend on the
website's availability. It is test evidence for the requested logo, not a
new managed template asset or permission to mail anything.
